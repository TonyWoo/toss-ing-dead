## 第 1 步：灰盒原型（等 Dash 试玩）

目标：只验证「套中爽不爽、套不中怕不怕」。

- 有：雨夜街景、套圈摊、雨；5×4 奖品场（茶杯、汽水瓶、招财猫、金猪，鞭炮炸退、铜锣定身）；竹圈的飞行、擦边、套中判定；
  鼠标蓄力 / 空格 / 触屏按住蓄力；僵尸逐步逼近、没套中就往前扑、抓人扣机会（三盏灯笼）；五轮流程、连中倍率、风；
  标题 / 收档 / 收工界面；合成音效、僵尸嗓音、《雨夜开镬》配乐。
- 已验证（2026-11-18，Linux 容器里的无头浏览器，软件渲染）：页面加载无报错，点「开档」能开局，按住松开能出手，
  没套中后僵尸进入扑步；截过标题和对局画面，调整了招牌、摊台高度、手上圈的位置。
- 没人上手验证：手感、射程、判定宽严、僵尸节奏、手机操作、音效和音乐的实际听感、手机帧率——全部等 Dash 试玩。
